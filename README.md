# Another Minimal Template for Digital Scholarlt Editions

Inspired by the previous project [Ed. a jekyll theme for minimal edition](https://minicomp.github.io/ed/), this repository provides a lightweight, customizable **Jekyll template** for creating and publishing a minimal digital scholarly editions as static websites. It is intended for teaching, prototyping, and developing sustainable digital editions using minimal computing principles, and it is still under construction. 

## 🌐 Live Preview

To view a demo (if hosted via GitHub Pages), visit:  
`https://susannalles.github.io/DSE_template/`

## 📁 Structure

- `index.md` – Homepage with a brief introduction to the edition
- `texts/` – Folder where HTML-encoded texts or transformed TEI files reside
- `_layouts/` – HTML templates for rendering content pages
- `_includes/` – Reusable site components (navigation, head, footer)
- `assets/` – CSS (`frutos2.css`), images, and future JavaScript
- `_config.yml` – Site metadata and configuration
- `sidebar.html`, `footer.html` – Custom layout elements

## 👌🏽 Features

- Clean and responsive layout for Homepage.
- Default pages with sidebar navigation.
- GitHub Pages-ready: deploy your edition with no server

## 🚀 How to Use

1. **Fork or clone** this repository.
2. Replace or edit the contents of the `texts/` folder.
3. Customize the homepage and layout as needed.
4. Commit your changes and enable GitHub Pages from the `Settings` > `Pages` section.
5. View your live site at `https://susannalles.github.io/DSE_template/`
